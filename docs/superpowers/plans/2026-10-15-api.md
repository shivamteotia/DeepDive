# MaxRIM Step 5 API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An authenticated FastAPI service over Postgres that lets one user create projects, upload PDFs (indexed in a crash-isolated child process), start verified research runs, and inspect their evidence and verification.

**Architecture:** Four new flat modules next to the existing `ingest.py` / `ask.py` / `research.py`: `db.py` (SQLAlchemy models), `auth.py` (scrypt + JWT), `jobs.py` (background ingestion via a 1-worker process pool, research runs in threads, restart recovery), `app.py` (`create_app()` factory with routes and dependencies as closures). Postgres runs from `docker-compose.yml`; unit tests use SQLite in-memory.

**Tech Stack:** Python 3.12 + uv, FastAPI, uvicorn, SQLAlchemy 2, psycopg 3, PyJWT, python-multipart, Qdrant Cloud, OpenAI.

**Spec:** `docs/superpowers/specs/2026-10-15-api-design.md`

## Global Constraints

- Python 3.12, dependencies via `uv add` only. No pip, no requirements.txt.
- This folder is **not a git repository**; the user commits. There are no commit steps — each task ends with a checkpoint: `uv run ruff check .` clean and `uv run pytest -m "not live" -q` green.
- Unit tests must not touch the network, Postgres, Docling or paid APIs. Anything that does is marked `@pytest.mark.live`.
- Never print, log, or echo `.env` values. Error messages stored in the DB have known secrets replaced with `***`.
- Every Qdrant query carries a `project_id` filter built server-side from an authorised project. Never accept it from a client.
- Model names come from `Settings` (env). Nothing reads `os.environ` outside `config.py`.
- Do **not** add `from __future__ import annotations` to `app.py`: FastAPI must resolve the `Annotated` dependency aliases defined inside `create_app`.
- Status values exactly: documents `queued | processing | ready | failed`; research runs `queued | running | completed | failed`.
- Limits exactly: password 12–1024 chars; project name 1–200 chars (stripped); question 3–2000 chars (stripped); `max_iterations` 1–5, default 3; upload ≤ 50 MB and must start with `%PDF-`; stored errors ≤ 500 chars.
- Not-owned project/document/run → `404` (never `403`). Missing/invalid/expired token → `401`.

## Review Focus

1. Server restarts while a PDF is processing → the document ends `failed` ("interrupted by server restart") and re-uploading the same file re-queues and indexes it. (Test added in Task 4.)
2. A research run starts while another document in the project is still `processing`, or has `failed` with partial vectors → search must only use chunks of `ready` documents. (Test added in Task 5.)
3. Upload filename contains path parts or Windows backslashes (`..\..\evil.pdf`) → display name is `evil.pdf`; the file on disk is named by its sha256 only. (Test added in Task 4.)
4. A token signed with `alg: none`, signed with another secret, or for a user that no longer exists → `401`. (Tests added in Task 2.)
5. Whitespace-only project name or question → `422`, not a blank project or a paid empty run. (Tests added in Tasks 3 and 5.)

```python
"""Postgres (SQLite in unit tests) models for users, projects, documents and research runs."""

import uuid
from datetime import UTC, datetime

from sqlalchemy import JSON, DateTime, ForeignKey, Integer, String, Text, UniqueConstraint, Uuid, create_engine
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, sessionmaker
from sqlalchemy.pool import StaticPool


def utcnow() -> datetime:
    return datetime.now(UTC)


class Base(DeclarativeBase):
    pass


class User(Base):
    __tablename__ = "users"
    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    email: Mapped[str] = mapped_column(String(320), unique=True)
    password_hash: Mapped[str] = mapped_column(String(300))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)


class Project(Base):
    __tablename__ = "projects"
    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    owner_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("users.id"), index=True)
    name: Mapped[str] = mapped_column(String(200))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)


class Document(Base):
    __tablename__ = "documents"
    __table_args__ = (UniqueConstraint("project_id", "sha256"),)
    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    project_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("projects.id"), index=True)
    filename: Mapped[str] = mapped_column(String(255))
    sha256: Mapped[str] = mapped_column(String(64))
    status: Mapped[str] = mapped_column(String(20), default="queued")
    chunk_count: Mapped[int | None] = mapped_column(Integer)
    error: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)
    updated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow, onupdate=utcnow)


class ResearchRun(Base):
    __tablename__ = "research_runs"
    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    project_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("projects.id"), index=True)
    question: Mapped[str] = mapped_column(Text)
    max_iterations: Mapped[int] = mapped_column(Integer, default=3)
    status: Mapped[str] = mapped_column(String(20), default="queued")
    result: Mapped[dict | None] = mapped_column(JSON)
    error: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)
    finished_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))


def make_sessions(database_url: str) -> sessionmaker:
    """Create missing tables and return a session factory.
    ponytail: create_all, no migrations; add Alembic at the first schema change on data that must be kept."""
    kw = {"connect_args": {"check_same_thread": False}, "poolclass": StaticPool} if database_url.startswith("sqlite") else {}
    engine = create_engine(database_url, **kw)
    Base.metadata.create_all(engine)
    return sessionmaker(engine, expire_on_commit=False)
```

```python
"""Password hashing (stdlib scrypt) and HS256 access tokens."""

import hashlib
import hmac
import os
import uuid
from datetime import UTC, datetime, timedelta

import jwt

_SCRYPT = {"n": 2**14, "r": 8, "p": 1, "dklen": 32}


def _derive(password: str, salt: bytes) -> bytes:
    return hashlib.scrypt(password.encode("utf-8", "surrogatepass"), salt=salt, **_SCRYPT)


def hash_password(password: str) -> str:
    salt = os.urandom(16)
    return f"scrypt${salt.hex()}${_derive(password, salt).hex()}"


def verify_password(password: str, stored: str) -> bool:
    try:
        algo, salt_hex, digest_hex = stored.split("$")
        salt, digest = bytes.fromhex(salt_hex), bytes.fromhex(digest_hex)
    except ValueError:
        return False
    if algo != "scrypt" or not salt:
        return False
    return hmac.compare_digest(_derive(password, salt), digest)


# Checked against when the email is unknown, so response time doesn't reveal which accounts exist.
DUMMY_HASH = hash_password("timing-equaliser")


def create_token(user_id: uuid.UUID, secret: str, minutes: int) -> str:
    now = datetime.now(UTC)
    return jwt.encode({"sub": str(user_id), "iat": now, "exp": now + timedelta(minutes=minutes)}, secret, algorithm="HS256")


def decode_token(token: str, secret: str) -> uuid.UUID | None:
    """User id from a valid, unexpired HS256 token; None for anything else."""
    try:
        payload = jwt.decode(token, secret, algorithms=["HS256"], options={"require": ["exp", "sub"]})
        return uuid.UUID(payload["sub"])
    except (jwt.PyJWTError, ValueError):
        return None
```

```python
"""MaxRIM HTTP API.

Run: docker compose up -d   then   uv run uvicorn app:create_app --factory
Docs: http://127.0.0.1:8000/docs
"""

import uuid
from collections.abc import Iterator
from contextlib import asynccontextmanager
from pathlib import Path
from types import SimpleNamespace
from typing import Annotated

from fastapi import Depends, FastAPI, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from pydantic import BaseModel, ConfigDict, Field
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

import auth
import db
from config import Settings

ROOT = Path(__file__).parent
EMAIL_PATTERN = r"^[^@\s]+@[^@\s]+\.[^@\s]+$"


class RegisterIn(BaseModel):
    email: str = Field(pattern=EMAIL_PATTERN, max_length=320)
    password: str = Field(min_length=12, max_length=1024)


class LoginIn(BaseModel):
    email: str = Field(max_length=320)
    password: str = Field(max_length=1024)


class UserOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: uuid.UUID
    email: str


def create_app(settings: Settings | None = None, *, qdrant=None, openai_client=None, runner=None,
               upload_dir: Path | None = None) -> FastAPI:
    settings = settings or Settings()
    if len(settings.jwt_secret) < 32:
        raise ValueError("JWT_SECRET must be at least 32 characters")
    state = SimpleNamespace(settings=settings, sessions=db.make_sessions(settings.database_url))

    @asynccontextmanager
    async def lifespan(_app):
        yield

    app = FastAPI(title="MaxRIM", lifespan=lifespan)
    app.state.maxrim = state

    def get_db() -> Iterator[Session]:
        with state.sessions() as s:
            yield s

    DB = Annotated[Session, Depends(get_db)]
    bearer = HTTPBearer(auto_error=False)

    def current_user(creds: Annotated[HTTPAuthorizationCredentials | None, Depends(bearer)], s: DB) -> db.User:
        uid = auth.decode_token(creds.credentials, settings.jwt_secret) if creds else None
        user = s.get(db.User, uid) if uid else None
        if user is None:
            raise HTTPException(401, "Not authenticated", headers={"WWW-Authenticate": "Bearer"})
        return user

    CurrentUser = Annotated[db.User, Depends(current_user)]

    @app.get("/health")
    def health():
        return {"status": "ok"}

    @app.post("/auth/register", status_code=201, response_model=UserOut)
    def register(body: RegisterIn, s: DB):
        user = db.User(email=body.email.lower(), password_hash=auth.hash_password(body.password))
        s.add(user)
        try:
            s.commit()
        except IntegrityError:
            s.rollback()
            raise HTTPException(409, "Email already registered") from None
        return user

    @app.post("/auth/login")
    def login(body: LoginIn, s: DB):
        user = s.scalar(select(db.User).where(db.User.email == body.email.lower()))
        ok = auth.verify_password(body.password, user.password_hash if user else auth.DUMMY_HASH)
        if user is None or not ok:
            raise HTTPException(401, "Invalid email or password")
        return {"access_token": auth.create_token(user.id, settings.jwt_secret, settings.access_token_minutes),
                "token_type": "bearer"}

    @app.get("/api/v1/projects")
    def list_projects(user: CurrentUser):  # placeholder body replaced in Task 3
        return []

    return app
```

```python
"""Background work for the API: PDF ingestion in a child process, research runs in threads, restart recovery."""

import threading
import uuid
from concurrent.futures import ProcessPoolExecutor
from concurrent.futures.process import BrokenProcessPool
from dataclasses import dataclass
from pathlib import Path

from sqlalchemy import update
from sqlalchemy.orm import Session, sessionmaker

import db
from config import Settings

RESTART_ERROR = "interrupted by server restart"


@dataclass
class State:
    settings: Settings
    sessions: sessionmaker
    qdrant: object
    openai: object
    runner: object  # IngestRunner, or a test fake with .run(*args) and .shutdown()
    upload_dir: Path


def ingest_in_child(project_id: str, pdf_path: str, filename: str, collection: str) -> int:
    """Runs inside the worker process with its own clients. Returns the document's chunk count in Qdrant."""
    from openai import OpenAI
    from qdrant_client import QdrantClient

    import ingest

    s = Settings()
    qdrant = QdrantClient(url=s.qdrant_cluster_endpoint, api_key=s.qdrant_api_key)
    path = Path(pdf_path)
    ingest.ingest(project_id, path, qdrant=qdrant, openai_client=OpenAI(api_key=s.openai_api_key), collection=collection,
                  embed_model=s.openai_embed_model, source_filename=filename)
    return qdrant.count(collection, count_filter=ingest.doc_filter(project_id, ingest.sha256_file(path)), exact=True).count


class IngestRunner:
    """Ingests in a single worker process. Docling is memory-heavy and can crash natively (Li2024.pdf did); in a
    child process that fails one document instead of killing the API.
    ponytail: one PDF at a time; move to a separate worker polling the documents table when uploads get heavy."""

    def __init__(self, fn=ingest_in_child):
        self.fn = fn
        self._lock = threading.Lock()
        self._pool: ProcessPoolExecutor | None = None

    def run(self, *args) -> int:
        with self._lock:
            if self._pool is None:
                self._pool = ProcessPoolExecutor(max_workers=1)
            try:
                return self._pool.submit(self.fn, *args).result()
            except BrokenProcessPool:
                self._pool.shutdown(wait=False)
                self._pool = None
                raise RuntimeError("PDF parser crashed (native error); this PDF may be unsupported") from None

    def shutdown(self) -> None:
        if self._pool is not None:
            self._pool.shutdown(cancel_futures=True)
            self._pool = None


def short_error(exc: Exception, settings: Settings) -> str:
    msg = f"{type(exc).__name__}: {exc}"
    for secret in (settings.openai_api_key, settings.qdrant_api_key, settings.jena_ai_api_key, settings.jwt_secret):
        if secret:
            msg = msg.replace(secret, "***")
    return msg[:500]


def claim(s: Session, model, row_id: uuid.UUID, from_status: str, to_status: str) -> bool:
    """Atomically move a row between statuses; False if it wasn't in from_status (someone else has it)."""
    n = s.execute(update(model).where(model.id == row_id, model.status == from_status).values(status=to_status)).rowcount
    s.commit()
    return n == 1


def ingest_document(state: State, document_id: uuid.UUID) -> None:
    with state.sessions() as s:  # short sessions: never hold a transaction open while Docling runs for minutes
        if not claim(s, db.Document, document_id, "queued", "processing"):
            return
        doc = s.get(db.Document, document_id)
        args = (str(doc.project_id), str(state.upload_dir / str(doc.project_id) / f"{doc.sha256}.pdf"), doc.filename,
                state.settings.qdrant_collection)
    try:
        values = {"status": "ready", "chunk_count": state.runner.run(*args), "error": None}
    except Exception as exc:  # recorded on the document; the API keeps serving
        values = {"status": "failed", "error": short_error(exc, state.settings)}
    with state.sessions() as s:
        s.execute(update(db.Document).where(db.Document.id == document_id).values(**values))
        s.commit()


def recover_interrupted(sessions: sessionmaker) -> None:
    """On startup: work that was in flight when the server stopped will never finish; mark it failed (retryable)."""
    with sessions() as s:
        s.execute(update(db.Document).where(db.Document.status.in_(("queued", "processing")))
                  .values(status="failed", error=RESTART_ERROR))
        s.execute(update(db.ResearchRun).where(db.ResearchRun.status.in_(("queued", "running")))
                  .values(status="failed", error=RESTART_ERROR, finished_at=db.utcnow()))
        s.commit()
```

```python
import hashlib
import re

from fastapi import BackgroundTasks, Response, UploadFile

import jobs

MAX_UPLOAD_BYTES = 50 * 1024 * 1024


def save_pdf(file: UploadFile, dest: Path) -> str:
    """Copy the upload to dest in 1 MB chunks, enforcing the PDF signature and size limit. Returns sha256 hex.
    ponytail: Starlette has already spooled the body to a temp file; a hard body limit belongs in a reverse proxy."""
    digest, size = hashlib.sha256(), 0
    with dest.open("wb") as out:
        while chunk := file.file.read(1 << 20):
            if size == 0 and not chunk.startswith(b"%PDF-"):
                raise HTTPException(400, "File is not a PDF")
            size += len(chunk)
            if size > MAX_UPLOAD_BYTES:
                raise HTTPException(413, f"File larger than {MAX_UPLOAD_BYTES // (1024 * 1024)} MB")
            digest.update(chunk)
            out.write(chunk)
    if size == 0:
        raise HTTPException(400, "File is not a PDF")
    return digest.hexdigest()


def display_name(filename: str | None) -> str:
    return re.split(r"[\\/]", filename or "")[-1][:255] or "upload.pdf"
```

```python
def run_research(state: State, run_id: uuid.UUID) -> None:
    with state.sessions() as s:
        if not claim(s, db.ResearchRun, run_id, "queued", "running"):
            return
        run = s.get(db.ResearchRun, run_id)
        project_id, question, max_iterations = str(run.project_id), run.question, run.max_iterations
        ready = list(s.scalars(select(db.Document.sha256).where(db.Document.project_id == run.project_id,
                                                                  db.Document.status == "ready")))
    cfg = state.settings

    def search_fn(q: str) -> list[dict]:  # project and ready-document filters are fixed here, server-side
        return ask.search(state.qdrant, state.openai, collection=cfg.qdrant_collection, embed_model=cfg.openai_embed_model,
                          project_id=project_id, question=q, k=RESEARCH_K, rerank_model=cfg.reranker_model,
                          rerank_api_key=cfg.jena_ai_api_key, sha256_in=ready)

    try:
        result = research.run(state.openai, search_fn=search_fn, project_id=project_id, model=cfg.openai_model,
                              fast_model=cfg.openai_fast_model, guard_model=cfg.openai_guard_model, question=question,
                              max_iterations=max_iterations)
        values = {"status": "completed", "result": research.audit_record(result), "error": None}
    except Exception as exc:  # recorded on the run; the API keeps serving
        values = {"status": "failed", "error": short_error(exc, cfg)}
    with state.sessions() as s:
        s.execute(update(db.ResearchRun).where(db.ResearchRun.id == run_id).values(**values, finished_at=db.utcnow()))
        s.commit()
```
